How CAPACITY CONNECT Works

A unified, multi-role structure designed for college technical capacity enhancement.

1. Trainees & Students

Register an account, browse accredited courses, enroll in one click, download study materials, and complete quizzes.

  • One-click enrollment
  • Access PDF lecture notes
  • Automated MCQ evaluations
2. Faculty Trainers

Create curriculum topics, upload PDF resources to Supabase Storage, create multiple-choice quizzes, and monitor students.

  • Design courses & objectives
  • Upload learning documents
  • Track student test scores
3. Administrators

Maintain academic quality, review and approve or reject proposed courses, broadcast notices, and inspect platform reports.

  • Course verification & approval
  • User directory governance
  • Institutional announcements

About CAPACITY CONNECT

CAPACITY CONNECT is developed for the Internet & Web Programming Lab based on the Smart India Hackathon (SIH 2026) Problem Statement SIH26075.

It proves end-to-end full-stack capabilities with real PostgreSQL database tables, Supabase Auth session management, Supabase Storage for PDF resources, and strict Row Level Security (RLS) policies.

Tech Stack: HTML5, CSS3, JS, Bootstrap 5
Backend: Supabase PostgreSQL & Auth
Storage: Supabase Buckets (PDFs)
